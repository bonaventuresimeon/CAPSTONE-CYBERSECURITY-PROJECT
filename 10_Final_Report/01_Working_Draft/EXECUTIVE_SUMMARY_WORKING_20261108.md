# Executive Summary — Working Draft
HanTech's capstone assessment, “From Vulnerability to Compliance: Securing Legacy and Cloud Systems,” examines the security implications of legacy services and proposes risk-based controls, governance policies and cloud-security practices. The current technical evidence was collected in an isolated VirtualBox lab using Kali Linux (192.168.138.10) and Metasploitable 2 (192.168.138.20) on the Internal Network CAPSTONE138_ISOLATED. This topology is not host-only networking. The second system mentioned in the brief has not yet been identified; Dev Guru has therefore remained out of scope pending instructor clarification.

An initial Nmap 7.98 TCP service/version inventory identified 23 open and 977 closed ports within the default top-1,000 TCP port set. Follow-up read-only checks identified several material exposures. These include an NFS root export to wildcard clients with read/write access and no_root_squash; anonymous SMB share enumeration; default lab credentials displayed on the HTTP landing page; unsupported Apache/PHP versions; legacy Telnet/r-services listeners; legacy Tomcat HTTP/AJP connectors; and a Mutillidae configuration resource that returned HTTP 200 and text/plain to an independent Kali HEAD request.

The Samba CVE-2007-2447 condition remains a high-confidence applicability candidate because the observed Samba version and active username-map setting match upstream prerequisites, but the installed binary's exact patch provenance has not been established. The PHP and Apache advisory reviews did not establish specific CVE applicability and remain downgraded research leads. The Mutillidae resource's remote availability is confirmed, but its response body and any secret values were deliberately not retrieved; credential validity and downstream database impact remain unverified.

The assessment was deliberately non-exploitative. No exploitation, brute force, password submission, NFS mount, remote file write, upload, deletion, database access or vulnerability NSE scan was performed. Accordingly, the results describe the training lab only and must not be attributed to HanTech production systems without a separately authorised assessment.

Priority recommendations include removing unsafe wildcard NFS exports, upgrading unsupported software, disabling unnecessary legacy services, restricting anonymous SMB access, removing exposed default credentials and protecting application configuration files. The risk register, security control mapping, GRC policy pack and cloud-security baseline are working drafts pending review by the assigned team members and confirmation of HanTech's business context and cloud environment.

The final report and presentation remain in progress. Risk ratings, final selection of five reportable findings, policy approval, cloud-specific conclusions and any production-system statements require validation before submission.
